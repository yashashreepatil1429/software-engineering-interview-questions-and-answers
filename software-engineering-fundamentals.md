Software Engineering Fundamentals

1. What is Software Engineering?

Software Engineering is a systematic approach to designing, developing, testing, deploying, and maintaining software applications.

It follows engineering principles to develop reliable, efficient, secure, and maintainable software.

2. What is Software?

Software is a collection of programs, instructions, and related data that tells a computer how to perform specific tasks.

Examples:

- System software – Windows, Linux
- Application software – MS Word, Chrome
- Web applications – Amazon, Gmail

3. What is SDLC?

SDLC stands for Software Development Life Cycle. It is a step-by-step process used to develop high-quality software.

Main phases:

1. Requirement Analysis
2. Planning
3. System Design
4. Development (Coding)
5. Testing
6. Deployment
7. Maintenance

4. What are the different SDLC models?

The major SDLC models are:

- Waterfall Model
- Agile Model
- Spiral Model
- V-Model
- Iterative Model
- Prototype Model
- Incremental Model

5. What is the Waterfall Model?

The Waterfall Model is a traditional software development model where each phase must be completed before moving to the next phase.

Example: First collect requirements, then design, develop, test, and deploy the application.

6. What is Software Testing?

Software Testing is the process of checking software to identify bugs, errors, and defects and verify that it works according to requirements.

7. What is the difference between Waterfall and Agile?

| Waterfall | Agile |
|---|---|
| Sequential approach | Iterative approach |
| Changes are difficult | Changes are easier |
| Testing usually follows development | Testing happens continuously |
| Less customer involvement | Regular customer feedback |
| Fixed requirements | Flexible requirements |

8. What is Unit Testing?

Unit Testing is the process of testing individual components or functions of an application separately.

Example: Testing a login validation function to check whether it correctly accepts valid credentials.

9. What is Software Architecture?

Software Architecture defines the overall structure of a software application, including its components, relationships, and communication.

Example: Three-tier architecture:

- Presentation Layer
- Business Logic Layer
- Database Layer

10. What is Modular Programming?

Modular programming is a programming approach where a large application is divided into smaller independent modules.

Each module performs a specific task.

Advantages:

- Code reusability
- Easy debugging
- Easy maintenance
- Better organization
